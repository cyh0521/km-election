# 金門行政區選單圖示

資料來源：[內政部國土測繪中心下載專區](https://maps.nlsc.gov.tw/pro/download.jsp)，
「村(里)界(TWD97經緯度)」，VILLAGE_NLSC_1150817，2026-10-26 下載。
官方原始檔：https://maps.nlsc.gov.tw/download/村(里)界(TWD97經緯度).zip
政府資料開放授權條款：https://data.gov.tw/license

依 COUNTYCODE=09020 篩出金門，將同鄉鎮的村里及未編村里面積合併，產出六鄉鎮與三十七村里圖示。
經緯度依金門緯度修正比例；刪除小於最大面積 1.2% 的碎島，
省略距主體超過主體跨度 65% 的遠方島礁，以免主要區域縮得過小。
烈嶼鄉與黃埔村圖示僅保留主要區域輪廓，移除小島後重新計算取景、等比例放大置中。
以圖形跨度 0.9% 簡化海岸轉折，每張各自等比例置中。
PNG 使用超取樣繪製，192×192，呈現時 32×32，避免細線鋸齒。
青綠外框與淡綠填色搭配暖金三角形。用途為類別選單示意，不表示歷年選區範圍。

重建：安裝 pyshp、shapely、Pillow，執行
`python tools/build-boundary-icons.py <官方村里 SHP 路徑>`。
manifest.js 使用鄉鎮與村里全名對應檔案，村里不可跨鄉鎮誤配。
